# React Dashboard

## Objetivo
Desenvolver o dashboard web utilizando React e JavaScript.

## Responsabilidades
- Utilizar componentes reutilizaveis.
- Integrar a API Node.js e comunicacao em tempo real.
- Implementar autenticacao e controle de permissao na interface.
- Apresentar metricas, alertas e historicos.
- Utilizar Styled Components para estilizacao.
- Tratar carregamento, erros e indisponibilidade.

## Entrega
Dashboard funcional, responsivo e integrado ao backend.
