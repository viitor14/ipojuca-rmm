# Design System

## Objetivo
Criar uma identidade visual consistente para o RMM.

## Diretrizes
- Criar identidade moderna, profissional e minimalista.
- Evitar layouts genericos com aparencia de template de IA.
- Definir cores, tipografia, espacamentos e componentes.
- Garantir consistencia entre todas as telas.
- Priorizar legibilidade e acessibilidade.

## Entrega
Guia visual e especificacao dos componentes da interface.
