# UX Dashboard

## Objetivo
Projetar uma experiencia eficiente para a equipe de TI.

## Responsabilidades
- Organizar telas de unidades e computadores.
- Facilitar identificacao de falhas e alertas.
- Planejar navegacao e detalhes do equipamento.
- Diferenciar estados normal, alerta, critico e offline.
- Projetar para desktop e telas menores.

## Entrega
Fluxos de navegacao e especificacoes das telas.
