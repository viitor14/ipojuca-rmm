# Data Modeling

## Objetivo
Projetar a estrutura de dados MySQL do sistema RMM.

## Responsabilidades
- Modelar unidades, computadores, agentes e usuarios.
- Modelar metricas, alertas, tarefas e historico de eventos.
- Definir chaves, relacionamentos e restricoes.
- Criar migrations versionadas.
- Aplicar principios de minimizacao e protecao de dados.

## Entrega
Modelo entidade relacionamento e estrutura SQL documentada.
